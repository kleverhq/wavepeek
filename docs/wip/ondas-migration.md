# Ondas backend migration

## Goal and acceptance

Replace Wellen and the project-owned FSDB reader with Ondas from `release/1.0.0-rc`, pinned by Git SHA. Preserve VCD/FST/FSDB command behavior, browser VCD/FST support, tests, and benchmark cases. GHW is out of scope. Compare FST and FSDB performance against `v3.0.1` with existing thresholds; VCD timing is an opt-in additional benchmark. RSS is out of scope. Do not modify Ondas: report demonstrated upstream defects with reproductions.

## Implementation

Baseline: `883f96d` (`v3.0.1`). Ondas checkout: `/home/esynr3z/projects/ondas/ondas-lib`. The public facade remains in `src/waveform/mod.rs`; `ondas_backend.rs` owns hierarchy adaptation, expression metadata, batched sampling, cached range traces, and indexed trace offsets. The preceding raw tick replaces the private global-timestamp predecessor; external event/change/property tests pass. No exact global timestamp table is claimed.

Unpacked array indices retain Wavepeek's public synthetic scope components (`memory.[0]`). All 12 formerly failing FST benchmark commands now match baseline output byte-for-byte. The original full timing run predates this fix and cannot establish acceptance.

The old `fsdb_hierarchy.rs` builder and `fsdb_time.rs` parser were test-only implementations of the retired reader and are removed. Raw timestamp scaling and overflow remain covered through production `Waveform::metadata()` tests. Thirteen hierarchy checks now exercise production alias mapping or real converter-produced FSDB files: sorting/depth, direct/recursive listing, missing-path errors, duplicate declarations, repeated-scope merging, escaped local names with separators, hidden-scope exclusion, literal index/range suffixes, and enum declaration/type/label metadata. The SDK-backed replacements verify sampled values/events as well as hierarchy shape. FSDB startup diagnostics are suppressed around native opening.

## Decisions

- Git/SHA dependency, not a persistent sibling path dependency.
- No implementation subagents. Final review alone uses Sol/high.
- Preserve benchmark workloads and thresholds (`max(5%, 5ms)` with best-sample confirmation).
- Maintainer-approved synthetic fixture correction: use explicit `event 1`, not Wellen's zero-width-parameter heuristic. Issue 18 was withdrawn; see `ondas-event-parameter.md`.
- Maintainer-approved SDK contract change: adopt Ondas's absolute `DT_NEEDED` paths and `linux64`/`LINUX64` selection. No RPATH requirement or old Reader overrides. This is not an upstream defect.
